# Checks

The checklist that was here now lives in `data/checks.csv` (study and across-study checks) and `data/claims.csv` (what each cited source is used to support).

Work through them on the **Checks** page (`verify.html`): mark each item, add notes or the quote and page, then save into the data folder and run `python3 build.py`.

Convention in the CSVs: text in `[Ours: ...]` or starting with `[Ours]` is our interpretation, not the authors'. Keep it marked or delete it.
